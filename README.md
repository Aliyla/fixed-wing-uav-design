Fixed-Wing UAV Conceptual Design

Overview

This project is a conceptual design study of a fixed-wing UAV, intended for long-endurance mapping and research missions. The goal is to apply aerospace engineering principles — including aerodynamic analysis, structural analysis, and performance estimation — to produce a complete conceptual design package.

This project is self-initiated as part of my personal development as a mechanical engineering student with a focus on aerospace systems.

Mission Specification

Mission: Long-endurance mapping/research
Max Takeoff Weight: 9kg
Payload: 1 kg (camera/sensor)
Target Endurance: 60-90 minutes
Cruise Speed: 15-18 m/s
Propulsion: Electric

Tools

MATLAB — performance analysis and plotting
Onshape — 3D CAD modeling
XFOIL — airfoil aerodynamic analysis
GitHub — version control and documentation

Project Phases

Mission definition and initial sizing
Airfoil selection and XFOIL analysis
CAD modeling in Onshape
Wing spar structural analysis
MATLAB performance plots
Final report and documentation
